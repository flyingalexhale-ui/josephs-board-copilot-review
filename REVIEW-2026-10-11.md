# First review findings (2026-10-11, claude.ai/code, report only)

Careful read of the money-handling code line by line; bridges and scanner only skimmed; display pages (channel, signals, night, web/) not reviewed. Findings marked as depending on broker behaviour are unverified against real Webull/IBKR.

## Money at risk
1. **SELL ALL and the algo can both sell the same shares (can leave you short).** ibkr-algo/algo/core_trader.py:277-282 (same in webull-algo), 297-318, 710-719; gateway/algoctl.py:96. During SELL ALL the algo only stops its own kill-switch sell; stop-loss/exit/trailing keep running, and SELL ALL cancelling the backup stop releases a held-back exit. Pressing Stop during SELL ALL rewrites the pause file without the `by: sellall` mark. Fix: in `_live()` refuse every order except the kill-switch close while pause file says `by: sellall`; `algoctl.post('stop')` keeps an existing `by`.
2. **Board safety stops, scheduled sell-all and Flip refused for positions over $5,000.** gateway/ticket.py:380-382 via gateway/orders.py:171. JB_TICKET_MAX ($5,000) applies to sells too; not in settings.env.example. Fix: skip the dollar cap for sells (or for board-automatic orders).
3. **One rejected order disables the algo's stop-loss for 15 min; three until restart.** core_trader.py:544-556, :311. Fix: closing orders bypass cooldown and halt like the kill switch (short retry gap); pause only entries.
4. **Live trader has no auto-restart and no alert when it dies/freezes.** gateway/guardian.py:281, :289; jb cmd_live. Heartbeat push skipped when RUN_<BROKER>_ALGO=off and muted while LIVE_RUNNING exists (file survives reboot). Fix: when LIVE_RUNNING exists, check heartbeat and that its PID is alive regardless of RUN_*_ALGO; push loudly if stale.
5. **Broker backup stop is off when you trade.** webull-algo/algo/paper_trader.py:168 (support_trading_session 'CORE'); ibkr-algo/algo/paper_trader.py:90 (normal route, not 8 pm-4 am). Fix: say so on the algo tab; check Webull accepts 'ALL'; consider not holding overnight unless trader confirmed alive.
6. **Overnight price stalls not fixed, so stop-loss goes blind.** Webull paper_trader.py:47-60, :315 and bridges/webull_bridge.py:76-86 (watchdog only 4 am-8 pm); ibkr-algo paper_trader.py:281-296 (`_resubscribe` only re-requests the day route). Fix: include overnight in Webull stall window when overnight enabled; re-request `self.overnight` in `_resubscribe`.
7. **Backup-stop timeout/placement error can sell twice.** core_trader.py:680-688, 744-755. Fix: re-read broker position and open orders before giving up; after a placement error look the order up by client order ID before retrying.
8. **Webull SELL ALL and its automatic follow-up can sell more than held.** gateway/killswitch.py:655-666, 683-703; gateway/guardian.py:377-411. Fix: failed lookup = unknown, stop; wait for position update after any fill; follow-up only re-sells symbols from the original run and only if no order still open.
9. **Board stop/chase can stack a second sell while the first is being cancelled.** gateway/ticket.py:459 (missing PendingCancel/ApiPending/unknown Webull statuses). Fix: anything not clearly final (Filled, Cancelled, Rejected, Expired, Inactive) counts as open.
10. **Board safety stop stuck in "firing" after a gateway restart.** gateway/orders.py:318-321. Fix: at startup reset "firing" guards to "on" and recheck holdings.

## Daily loss limit
11. **Loss limit undercounts.** gateway/trading.py:201-220, gateway/watch.py:32. 40 h price memory loses the 8 pm reference on Mondays/after holidays; off-board symbols have no price; fills only every 5 (IBKR) / 10 (Webull) min. Fix: keep >= 4 days of prices; use broker price for off-board symbols; say on page the total can lag.

## Wrong numbers on the board
12. **Monday/post-holiday "vs close" numbers blank.** gateway/watch.py:32, 71-80. Morning cards empty, % vs close alerts never fire, conditional scheduled orders skipped, Signals/Channel lose vs-close. `last_close_ms` ignores holidays and uses 4 pm on early-close days. Fix: KEEP_S ~100 h; compute last close with lib/nyse_hours.py.
Checked correct: runstate.session_at, lib/nyse_hours.py, killswitch.session_now (holidays, observed days, Juneteenth, early closes, overnight only before a trading day). Gap: one-off closures.

## Security
13. **No password + listening on 0.0.0.0 = anyone on the Wi-Fi can SELL ALL/trade; `null` origin accepted.** gateway/gateway.py:707, :157; settings.env.example:10. Fix: refuse trading actions unless a password is set; treat origin `null` as cross-site; or listen only on localhost/Tailscale. (With a password set, login looked sound.)
